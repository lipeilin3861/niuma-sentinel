# 安全政策 · Security policy

## 简体中文

发现可能导致本机数据、摄像头记录或安装包安全受影响的问题，请在仓库的 Security 页选择「Report a vulnerability」。若入口暂不可用，请通过邮件联系派徕设计。[私下报告漏洞](https://github.com/lipeilin3861/niuma-sentinel/security/advisories/new) · [安全联系邮箱](mailto:986592286@qq.com)

请附上应用版本、Windows 版本、受影响功能、最小复现步骤和预期行为。分享示例或日志前，请移除摄像头帧、人脸照片、特征向量和个人资料。普通误报、漏检和设备兼容问题欢迎在 Issues 反馈。

发布包从 Releases 下载，可对照同版本的 `SHA256.txt` 校验。

## English

Please report possible issues affecting local data, webcam records, or installer safety using the repository's private vulnerability reporting. If that route is unavailable, email PLAY atelier. [Report privately](https://github.com/lipeilin3861/niuma-sentinel/security/advisories/new) · [Security contact](mailto:986592286@qq.com)

Include the app version, Windows version, affected feature, minimal steps to reproduce, and expected behavior. Before sharing examples or logs, remove camera frames, face photos, embeddings, and personal details. Use Issues for ordinary recognition or device compatibility feedback.

Download release builds from Releases and compare the file hash with the matching `SHA256.txt`.
